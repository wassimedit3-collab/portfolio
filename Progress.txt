## Changes Applied This Session

### 1. Portfolio Sub-Page Construction
- **Video page** (`portfolio-videos.html`): Cards now wrap in `<a>` linking to YouTube. Added `<img>` thumbnails from `assets/videos/`. Removed old video modal (CSS + JS cleaned out).
- **4 photography galleries** (portrait, commercial, personal, manipulation): Converted from empty `.gallery-thumb` divs to `<img>` tags with `loading="lazy"`, `width="800"`, `height="600"`. Lightbox updated to read `<img>` src instead of background-image.
- **Logo page** (`portfolio-logos.html`): Replaced 6-card grid with JS carousel (arrow buttons + dot indicators, smooth cubic-bezier transitions). Carousel module added to `script.js`. Images from `assets/logos/`.

### 2. Photo Gallery Masonry Layout
- `.gallery-masonry` added to CSS: uses `column-count: 3` (→ 2 at 768px → 1 at 480px).
- `.gallery-item` uses `break-inside: avoid; margin-bottom: 16px`.
- Images have `aspect-ratio: 4/3; object-fit: cover` to prevent layout shifts.

### 3. Navigation — Fixed Bottom Red Buttons
- **All 21 pages**: `.hero-nav-bottom` is now `position: fixed; bottom: 0; width: 100%` with dark bar + blur.
- `.hero-nav-link`: filled red (`--accent`) background, black text, padding 10px 24px.
- Active page uses `--burgundy` red.
- Added `body { padding-bottom: 72px }` to prevent content overlap.
- On `index.html`, nav moved out of `<header class="hero">` to standalone.

### 4. SEO Foundations
- **robots.txt**: Allows all crawlers, points to sitemap.
- **sitemap.xml**: Lists all 22 pages with priority levels.
- **Canonical URLs**: `<link rel="canonical">` on every page.
- **JSON-LD Person schema**: Added to `index.html` (name, jobTitle, email, sameAs YouTube channels).
- **Font weights reduced**: 18→12 variants (dropped italic Playfair, unused Rajdhani 300/400/700, unused Inter 700).

### 5. Performance Optimizations
- **Async Google Fonts**: Font CSS now loads with `media="print" onload="this.media='all'"` — non-render-blocking. Page paints instantly with fallback fonts.
- **defer on script.js**: JavaScript no longer blocks rendering.
- **defer on gallery JS**: `images-data.js` (42KB) and `gallery-render.js` (2KB) now load deferred on all 11 JS-driven gallery pages.
- **Preload hero-logo.svg**: Critical SVG loads early on `index.html`.
- **Broken image fallback**: `onerror="this.remove()"` on all gallery images — shows gradient placeholder instead of 404.
